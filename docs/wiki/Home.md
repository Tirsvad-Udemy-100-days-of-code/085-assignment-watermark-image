# Watermark Image

A small desktop application that uploads an image, adds a text or logo watermark and saves the result. It is the Day 85 assignment of the Udemy course "100 Days of Code: The Complete Python Pro Bootcamp", built in four steps. Each step has a page with a screenshot and a section on what the step taught.

| Page | Read it when you want to |
| --- | --- |
| [Setup](Setup) | create a local `.venv`, install the project, run the program and the tests |
| [Step 1: upload](Step-1-Upload) | see the window and the image upload |
| [Step 2: text watermark](Step-2-Text-Watermark) | add a text watermark with place and opacity |
| [Step 3: logo watermark](Step-3-Logo-Watermark) | use a picture as the watermark |
| [Step 4: save](Step-4-Save) | save the result without touching the original |

The source, the README and the project documents are in the repository.
