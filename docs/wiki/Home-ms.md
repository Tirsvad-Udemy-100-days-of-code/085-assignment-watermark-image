# Watermark Image

Aplikasi desktop kecil yang memuat naik imej, menambah watermark teks atau logo dan menyimpan hasilnya. Ini ialah tugasan Hari ke-85 kursus Udemy "100 Days of Code: The Complete Python Pro Bootcamp", dibina dalam empat langkah. Setiap langkah mempunyai satu halaman dengan tangkapan skrin dan bahagian tentang apa yang kita pelajari.

| Halaman | Baca apabila anda mahu |
| --- | --- |
| [Persediaan](Setup-ms) | mencipta `.venv` setempat, memasang projek, menjalankan program dan ujian |
| [Langkah 1: muat naik](Step-1-Upload-ms) | melihat tetingkap dan muat naik imej |
| [Langkah 2: watermark teks](Step-2-Text-Watermark-ms) | menambah watermark teks dengan kedudukan dan kelegapan |
| [Langkah 3: watermark logo](Step-3-Logo-Watermark-ms) | menggunakan gambar sebagai watermark |
| [Langkah 4: simpan](Step-4-Save-ms) | menyimpan hasil tanpa menyentuh fail asal |
| [Refleksi](Reflection-ms) | membaca apa yang sukar, apa yang mudah dan apa yang perlu dilakukan secara berbeza |

Kod sumber, fail README dan dokumen projek berada dalam repositori.
